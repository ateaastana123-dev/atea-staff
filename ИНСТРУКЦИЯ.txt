ATEA TEAM — обновление маскота Моти (21.10.2026)

ОБНОВЛЕНО: круглое лицо Моти, глянцевые клеверы, надпись ATEA TEAM.

1. GitHub: https://github.com/ateaastana123-dev/atea-staff
2. В репозитории откройте Add file → Upload files.
3. Перетащите файлы index.html, atea-team-icon.png, icon-192.png, icon-512.png, apple-touch-icon.png, manifest.webmanifest из архива.
4. Подтвердите замену существующих файлов и нажмите Commit changes.
5. После успешной публикации откройте https://ateaastana123-dev.github.io/atea-staff/ и обновите страницу.
6. На iPhone для обновления значка на домашнем экране может понадобиться удалить старый ярлык и добавить сайт снова через Safari → Поделиться → На экран Домой.

Code.gs находится в архиве для комплектности, но для изменения только дизайна НЕ НУЖНО заменять Code.gs и повторно развёртывать Apps Script.
